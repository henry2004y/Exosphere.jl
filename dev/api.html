Package Overview ​

Exosphere Module
julia
Exosphere

Standalone, zero-allocation planetary neutral exosphere models, PlasmaPopulations.jl-style neutral species and VDFs, EUV shadow and optical-depth/Chapman/ray attenuation, conservative one-way and two-way charge–neutral interaction kernels, structured neutral field containers, and adaptive dual-cell box quadrature.

Exosphere.NeutralSpecies Type
julia
NeutralSpecies{T<:Real}
NeutralSpecies(; m)
NeutralSpecies(formula::Union{Symbol, AbstractString})
NeutralSpecies(scale::UnitScale, formula::Union{Symbol, AbstractString})

Lightweight isbits neutral atom or molecule species with mass m.

  • NeutralSpecies(; m) stores bare numeric m as given (code units or SI kg) and converts Unitful.Quantity inputs to kilograms when Unitful is loaded.

  • NeutralSpecies(formula) parses chemical and nuclide formulas (such as :H, :O, "CO2", "H2O", "SO2", "D", "{18}O") and stores the standard molecular mass in SI kilograms (weight * U_SI), matching PlasmaPopulations.Particle(formula, 0).

  • NeutralSpecies(scale, formula) converts the parsed molecular mass directly into code units m / scale.m0.

  • NeutralSpecies{T}(s) converts precision (e.g., NeutralSpecies{Float32}(s)).

                      inner_radius = 0.0, photochem_radius = 0.0,
                      FT = Float64) -> ExosphereModel

Construct and validate a multi-component ExosphereModel from either a non-empty vector of NeutralComponentCode (legacy v0.1.0 path) or a tuple/vector of NeutralPopulation / AbstractNeutralProfile entries.

julia
integrate_exosphere_box!(sumN, sumNA, exo::AbstractNeutralModel, c::SVector{3, FT},
                         h::SVector{3, FT}, depth::Int, rcut::FT;
                         t = nothing) -> FT

Adaptively accumulate per-component neutral density (sumN) and EUV-attenuated neutral density (sumNA) in place over an axis-aligned box centered at c (relative to the planet center) with side widths h, excluding the interior sphere r < rcut.
